# convention-manager
a web-app for artists to calculate their manufacturing costs, pricing, discounts, and total profit from tabling at a convention

## Project plan

The [project plan](docs/PROJECT_PLAN.md) records the agreed MVP, offline sales tracker, architecture, implementation milestones, and later roadmap, including stock carry-over between conventions.

Use it as the starting point for future planning and implementation conversations. It includes a suggested prompt and guidance on making the plan available in new repository sessions.
